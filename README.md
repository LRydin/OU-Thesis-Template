# OU-Thesis-Template

This repository contains templates for Master's thesis developed at the Open University of The Netherlands for the Department of Environmental Sciences.

## Structure

The repository has three folder:
 - A template in LaTeX with the `OU.cls` class defining the standards for the template.
 - A LibreOffice template in `.ott` format.
 - An MS Word template in `.dotx` format.

The templates are designed in LaTeX and transformed into `.dotx` and `.ott`.
The folder `svgs` stores svg version of the logos and others that enter the `.dotx` and `.ott` templates. The LaTeX version does not depend on these.
